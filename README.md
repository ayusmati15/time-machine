# Time Machine Interactive Web App

A browser‑based time progression simulation application built with HTML, CSS, and JavaScript.

## Features

- Simulates time progression logic with delays and events
- Interactive UI that updates based on time
- Supports conditional transitions based on user action

## Tech Stack

- HTML  
- CSS  
- JavaScript
